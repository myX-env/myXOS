# myXシリーズ 完全対応表（XA〜XZ・全18作）

Windows標準機能（BAT／PowerShell／C#）のみで構成された、個人開発のWindows最適化ツール群。
設定ファイル・レジストリに極力依存せず、「名前」「構造」「記号」そのものが状態や機能を語る、という思想が全編を貫いている。

## 各ツール詳細

### XP｜myXPad（XP風メモ帳）
- シリーズ第1作目。コピペ作業に特化したメモ帳。後続17作の思想の原石がすべて未分化のまま同居している。
- 設定は一切保存されない仕様（「起動するたびにボタン連打で整える」）。
- 誤操作のバグから生まれた裏メニューなど、「現象から機能を見つける」というシリーズ共通スタイルの最初の実例。
- Windows XP風ビジュアルを再現、闇／明のテーマ切替、頭文字変換（Ctrl+H）など機能は多いが、外部状態を持たない一貫性は保たれている。

### XC｜myXConv（変換もどき）
- 「ツール」と「ファイル」の両方を独立変数として扱い、その場で自由に組み合わせて実行する実験台。入れ替えボタンで両者を対等に扱う。
- カレントフォルダの最初のサブディレクトリ（`subDirs[0]`）を無条件に参照する、「設定なしで決まった場所を見る」方式。
- Toolsフォルダ内にXH・XBへの呼び出し導線を持ち、シリーズ内ハブとしても機能。
- XSの前身。「渡すファイル固定・ツール選択」というXSの型は、XCの「両方可変」から機能を絞り込む形で確立された。

### XH｜myXHelper（Xヘルパー）
- アプリ一覧を配列に直書きし、コードそのものが実行ロジックかつマニュアルになっている「一体型」。
- HTA（HTML Application）でGUIを構築し、PowerShellの重さとHTML/CSSの手軽さを両立。起動は遅いが自由度が高い。
- 配列内にXB・XZへの直接リンクを持ち、シリーズの相互接続点の一つ。
- XAが外部フォルダ依存の動的型なのに対し、XHは完全に自己完結した静的型。

### XS｜myXSend（送る無双）
- 唯一「設定ファイル（hlp_setting.cfg）」を持つツールだが、その中身をマニュアル文書化することで「消されやすいcfg/ini」の弱点を克服。
- パーサーは`SendToFolderPath=`の1行だけを読み、それ以外はすべて人間向けの説明文として自由に書き込める。
- `.bat`/`.lnk`/`.ps1`を自動判別して適切な起動方法に翻訳する点で、本家「送る」より対応範囲が広い。
- XFの参照先オプションの一つ（`SendTo_bak`）として直結。

### XD｜myXDiff（比較転生）
- 機械的な差分抽出ではなく「人間が差分を確認する作業」を支援する方向に振り切った2窓比較ツール。
- ◆／◆◆による確認済み管理、!!!!!!ボタンによる高速A⇔B切替（動的比較）、▼ボタンによる文字縮小＝構造比較モードなど、人間の視覚的認知を利用した独自機能群。
- ≪ボタンでウィンドウ幅260pxまで縮小、比較ツールから細長いメモ帳へ「転生」する。
- 引数とクリップボードを同時利用してA/B両方の入力ソースを起動前に自動構築でき、XFのクリップボード補完をさらに発展させた形。
- 右クリック長押しの裏メニューも、操作ミスから発見された挙動を正式採用したもの。

### XZ｜myXZipRun（ZIPRUN）
- ZIP内のEXE／PowerShellを解凍せずそのまま実行できる軽量ランチャー。ZIPを「実行コンテナ」として扱う発想。
- 一時展開先は`%TEMP%\ExeCollection`固定、実行後は自動削除。config.ini・レジストリ不使用。
- XCの「トップフォルダを機械的に参照する」という無設定思想を、ZIP内部リストに転用した関係にある。
- XVと組み合わせることで、ZIP内EXEを実行せず「解凍のみ」→判定、という安全な確認フローが成立する（`XZ_pak_zipを開く.bat`）。

### XN｜myXName（命名マスター）
- 記号・分類タグの辞書（$symbols, $tags1, $tags2）から選んで組み立てる、能動的なリネーム補助ツール。
- 末尾記号「[丶]」「[冖]」など、シリーズ全体で使われる記号語彙を供給するマスター辞書としての役割を持つ。
- 自動化ツールが多いシリーズの中で、人間が毎回操作する必要がある性質上、シリーズ内で最も使用頻度が低いとされる。

### XW｜myXWorker（Xワーカー）
- PE（実行ファイル）ヘッダを自前でバイト解析し、32bit/64bit・GUI/コンソールを判定する簡易アナライザを内蔵。
- `@HELP_START@`〜`@HELP_END@`というシリーズ共通のヘルプ埋め込み規格を読み取り表示（XVの判定ロジックの縮小移植版）。
- bat実行前に`.bak`へ自動退避してから上書きするなど、事故防止の一手間が随所に入っている。
- 右クリックメニューからXZ・XB・User.bat（XRの操作対象）へ直接ジャンプでき、シリーズの司令塔的ポジション。

### XT｜myXTimemo9（タイメモ9）
- タイマー・メモ・クリップボード監視（テキスト／画像）を1〜9ページのスロットに束ねた多重機能ツール。
- 設定ファイル・レジストリ不使用の完全ポータブル。ファイルは「003_2.txt」のように自動命名され、名前自体がスロット位置を語る。
- 引数で最大9ファイルを渡すと自動で1〜9ページに振り分けられる。
- Shift+記録で時刻追加保存という隠し機能、クリップモニターの多重起動を正式仕様として許容するなど、「何をしてやろうか」という利用者主導の設計。

### XB｜myXBlank（変換BOX_空箱）
- アプリ自体は変換ロジックを一切持たず、「入力をファイル化→外部batを実行→結果表示」だけを行う空箱。
- DLLで機能を内蔵する発想を逆転し、外部batの差し替えだけで無限に機能拡張できる。
- "XB is not an app — it is a box for the user" というコンセプトそのものがシリーズの縮図。
- XWの右クリックメニューから直接呼び出される、シリーズの汎用変換ポート。

### XA｜myXAppBAT（BATランチャー）
- **myX版**：対象フォルダの`myX*.bat`を動的列挙。番号選択で実行、`@番号`でプレビュー（内容をtypeするだけ）。
- **Win版**：`win_list.txt`にWindows標準機能（cplファイル群・コントロールパネル項目等）を静的列挙。1と2（設定／dir）だけ特別扱いする"skip対策"実装。
- BATにGUIが作れないため、XKのテンキーアプリと連携し、マウス操作を疑似キーボード入力として送り込む仕組みで補完される。
- ファイル内に全ツールの通称対応表がベタ書きされており、シリーズのセルフドキュメント機能も兼ねる。

### XK｜myXKey（キーナビ）
- マウス操作だけでテンキー・矢印キー・コピペ操作を完結させる補助ツール。主にXA・XFとの連携を想定。
- ALTモード（矩形取得）は、「コンソール上で右クリック＝貼り付け」というOSの挙動を逆手に取ったクリップボード取得機構。
- 設定ファイル・レジストリ不使用のポータブル仕様。多重起動は非対応。
- BATという「GUIを作れない言語」の限界を、外部アプリでの入力偽装によって迂回する、シリーズの入力インターフェース担当。

### XF｜myXFull（フルBAT）
- XA（メニュー一覧）とXK（キーナビ）を内包し、さらに引数取得も自動化した最上位互換の「二刀流フル装備BAT」。
- `Clip_F2P.exe`によりクリップボード上のファイルクリップ／`file:///`URLをテキストパスに変換し、単体起動でも「送る」相当の挙動を実現する。
- `%~dpn0`（自分のファイル名）を参照先フォルダ名として使う仕組みがあり、これがXEの中継フォルダ判定ロジックに直接継承された。
- ファイル種別ごとの実行分岐（bat/ps1/exe/lnk）を持ち、実行前に確実にXKをkillするなど後始末も徹底。

### XE｜Exeway（中継EXE）
- レジストリには「Exeway.exeを呼ぶ」という1点だけを登録し、実際の起動対象はレジストリの外（`_Exeway`優先フォルダ／`Exeway`通常フォルダ）に委譲する裏ボス格ツール。
- フォルダの存在有無で「割込みON/OFF」を判定する、状態を持たない設計。
- 実行時は`Path.GetFileNameWithoutExtension`で自分の名前を取得し同名フォルダを参照——XFの`%~dpn0`と同一パターン。
- 運用フォルダ内では「≫（進む）」「≪（戻る）」「冖（区切り）」という独自記号文法で多階層メニューを実現している。

### XV｜myXView（Xビュー）
- EXE／BATを実行前に確認できる軽量ヘルプランチャー。実行ファイル種別・32/64bit・GUI/コンソール判定・埋め込みヘルプ表示・引数入力からそのまま実行までを一体化。
- 自作ツールはEXE末尾にUTF-8テキストを付加する独自方式でヘルプを埋め込み、通常のEXEとは判定範囲を切り分けている。
- XZと組み合わせることで、ZIP内のEXEを「解凍はするが実行はしない」安全な確認フローを構築できる。
- XWに判定ロジックがそのまま移植されている、シリーズの判定基盤。

### XR｜myXReturn（リターンBAT）
- コード74バイト。`ren`のみで自分自身とその親フォルダの名前を同時にトグルする状態反転バッチ。if文・フラグ・ログ・設定なし。
- 実際の用途は2モード：①自分自身（例：AAA.bat⇄_AAA.bat）を並び替え・有効無効の目印に、②固定入口ファイル`User.bat⇄_User.bat`をON/OFFスイッチとして使う。
- BATが実行中でも自分自身をrenameできるという「逐次読み込み型実行方式ゆえの隙」を利用しており、これはPython/PowerShellのようなスクリプト系言語でも再現可能（C#等コンパイル型は不可）。
- 「名前が状態そのもの」というシリーズ最大の思想を、最小コードで体現した裏ボス格。

### XI｜myXIndex（Xインデックス）
- フォルダツリーを行番号付きHTMLに変換し、`file:///`リンク付きで丸ごと出力する。
- 独自レンダリングエンジンを一切持たず、ブラウザという既製の巨大インフラに検索・プレビュー・翻訳・PDF・動画再生まで丸投げする発想。
- 全階層を一度にフラット出力するため「掘る」動作が不要、Ctrl+Fで全階層横断検索が可能。
- ソート順（ディレクトリ優先＋名前順）はシリーズの記号ルール（冖・丶が沈む等）をそのまま忠実に反映する。
- ブラウザ上でリンクをコピー→Clip_F2Pでパスに変換→XFで引数化、という経路で「見るだけの装置」から「ファイル選択インターフェース」にもなる。

### XL｜myXLine（インライン電卓）
- どこでも選択範囲をCtrl+Bで計算し、その場に「数式=結果」を貼り付けるインライン電卓。シリーズ18作の集大成。
- ファイル名の末尾サフィックス（`myXLine_sp.exe`等）でホットキー自体を切り替える、名前＝設定の最終形。
- `DataTable.Compute`による言語非依存の数式評価で、地域設定を問わず動作する「国境なきアプリ」。
- そろばんモードでは計算結果を▼▲の記号で8桁のそろばん珠配置に変換しクリップボードへ出力。当初はメモ帳型クリップモニターに内蔵されていたが、常駐コストを避けるため分離・手動起動化された。
- 右クリックメニューから同フォルダのファイルを列挙・起動できる、ミニランチャー機能も内包。

## シリーズ共通の設計思想

1. **状態を持たない／名前が状態を兼ねる**
   XR（renameのみで自己反転）、XE（自分の名前と同名フォルダを参照）、XF（`%~dpn0`）など、設定ファイルの代わりに「名前」そのものを状態管理の手段にする。

2. **構造・入れ物そのものを実行単位として使う**
   XE（フォルダの存在有無で判定）、XZ（ZIPを実行コンテナ化）、XI（フォルダツリーをHTML化）など、対象を変えながら繰り返し現れる。

3. **既存インフラへの丸投げ**
   XI（ブラウザにレンダリングを委任）、XL（.NET標準の数式評価エンジンを利用）など、独自エンジンを作らず既製の巨大な仕組みに乗る。

4. **記号による並び順・状態制御**
   `冖`（Unicode後方特性で確実に最後尾へ）、`丶`（軽めに沈める）、`≫`/`≪`（進む・戻る）など、視覚的意味と機能が一致した記号語彙をXNが辞書として供給し、XA・XE・XI等で実運用される。

5. **仕様から機能を作るのではなく、現象から機能を見つける**
   XP（誤操作のバグから裏メニュー）、XD（バグ由来の裏機能）、XK（コンソールの右クリック挙動を逆手に取る）など、意図しない挙動を消さず正式採用するスタイル。

6. **本体を薄くし、処理は外部に逃がす**
   XB（ロジックを持たない空箱）、XW／XVの分離可能な構造、XL/ClipMonの分離など、単一責務を保つための切り出し。

7. **借りたものは完全に元へ戻す**
   XF・XAのXKに対する確実なtaskkill、XLのクリップボード完全退避・復元など、一時的に借用したリソースを綺麗に返す一貫した後始末の美学。

## ツール間の主な連携経路

```
XI（可視化）→ ブラウザ（選択UI）→ Clip_F2P（URL→パス変換）→ XF（引数化）→ XA/XW等（実行）

XA（myXツール一覧）／XA_win（Windows機能一覧）⇄ XK（マウス→キー入力変換）

XF = XA + XK を内包 + クリップボード自動取得（Clip_F2P経由）

XW（GUI司令塔）→ 右クリックメニューから XZ／XB／User.bat（XR操作対象）へ直接遷移
XW 内部に XV の判定ロジック（PE解析・ヘルプ抽出）を移植

XZ（ZIP内実行）+ XV（実行前判定）→ ZIP内EXEを「解凍のみ・実行せず」安全確認

XC（ツール×ファイルの自由な組み合わせ）→ 純化 → XS（1ファイル固定・送る特化）
XC の Tools フォルダ内から XH・XB を直接呼び出し

XH（固定リスト直書き）内から XB・XZ への導線を保持

XS の SendTo_bak フォルダ ⇄ XF の参照先オプションの一つ

XF の %~dpn0（自分の名前を参照フォルダ化）→ XE の中継フォルダ判定ロジックへ継承

XN（記号辞書：冖・丶等）→ XA・XE・XI 等の並び順制御で実運用

XL（そろばんモード出力）→ LiveClip（クリップボード監視表示）
```
