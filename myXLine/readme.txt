myXLine - インライン電卓 v1.0 -
=======================================
【ファイル構成】
myXLine
├ myXLine.exe　：インライン電卓本体
├ LiveClip.exe ：テキスト専用クリップモニター
└ readme.txt　：このファイル

【動作環境】
・Windows XP 以降
・.NET Framework 4.0

【概要】
文字入力できる場所で計算式を範囲選択し、
ホットキーを押すだけで「数式=結果」を入力できます。

例：
2^2 → 2^2=4

通常モードではクリップボードを元の状態へ復元します。
そろばんモードでは、貼り付け後に計算結果を8桁固定の
そろばん表示へ変換してクリップボードへ転送します。

LiveClip.exe を起動すると、クリップ内容を
リアルタイムで表示できます。

【使い方】

1. myXLine.exe を起動します。（常駐）
2. 必要に応じて LiveClip.exe を起動します。
3. 計算式を範囲選択します。
4. ホットキーを押します。
5. 「=結果」が追加されます。
6. そろばんモードでは、クリップ内容が
   　そろばん表示へ切り替わります。

【対応演算】
+　-　*　/　^（べき乗）
() による計算も可能です。

【モード切替】
タスクトレイのアイコンを右クリックします。

・クリップ：通常モード
　貼り付け後、クリップボードを元の状態へ復元します。

・クリップ：そろばんモード
　貼り付け後、計算結果をそろばん表示へ変換して
　クリップボードへ保存します。

【ホットキー変更】
EXEをリネームするだけで変更できます。

myXLine.exe　　　Ctrl+B（標準）
myXLine_a.exe　　Ctrl+A
myXLine_x.exe　　Ctrl+X
myXLine_sp.exe　 Ctrl+Space
myXLine_sl.exe　 Ctrl+/
myXLine_sc.exe　 Ctrl+;
myXLine_cl.exe　 Ctrl+:
myXLine_dt.exe　 Ctrl+.
myXLine_cm.exe　 Ctrl+,
myXLine_mu.exe　 Ctrl+無変換

【LiveClip】
・テキスト専用クリップモニター
・クリップ内容をリアルタイム表示
・ダブルクリックでフォント変更

【注意】
・ホットキーはWindowsや他ソフトとの競合、
　キーボード配列、IME設定などにより
　使用できない場合があります。
・動作しない場合は、別のキー名へ
　リネームしてお試しください。
・計算できない式は変換されません。
・そろばんモードはクリップ監視ソフトとの
　組み合わせで利用すると便利です。
