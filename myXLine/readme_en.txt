【System Requirements】
* Windows XP or later
* .NET Framework 4.0

【Overview】
Select a mathematical expression anywhere you can enter text,
then press the hotkey to insert the result instantly.

Example:

2^2 → 2^2=4

In Normal Mode, the clipboard is restored after the calculation.

In Soroban Mode, the calculation result is converted into an
8-digit soroban (Japanese abacus) text display and copied to the clipboard.

Run LiveClip.exe to monitor clipboard contents in real time.

【Usage】
1. Run myXLine.exe (resident application).
2. Optionally run LiveClip.exe.
3. Select a mathematical expression.
4. Press the hotkey.
5. "=Result" is inserted after the expression.
6. In Soroban Mode, the clipboard is replaced with the soroban display.

【Supported Operators】
+　-　*　/　^　(Exponentiation)
Parentheses () are also supported.

【Clipboard Modes】
Right-click the tray icon.

Normal Mode
* Restores the original clipboard after calculation.

Soroban Mode
* Replaces the clipboard with a soroban text representation of the result.

【Changing the Hotkey】
Simply rename the executable.
myXLine.exe　　　Ctrl+B (Default)
myXLine_a.exe　　Ctrl+A
myXLine_x.exe　　Ctrl+X
myXLine_sp.exe　 Ctrl+Space
myXLine_sl.exe　 Ctrl+/
myXLine_sc.exe　 Ctrl+;
myXLine_cl.exe　 Ctrl+:
myXLine_dt.exe　 Ctrl+.
myXLine_cm.exe　 Ctrl+,
myXLine_mu.exe　 Ctrl+Muhenkan (Japanese Keyboard)

【LiveClip】
* Text-only clipboard monitor
* Displays clipboard contents in real time
* Double-click to change the font

【Notes】
* Hotkeys may not work depending on Windows settings,
  keyboard layout, IME, or conflicts with other software.
* If a hotkey does not work, rename the executable
  to use another key.
* Invalid expressions are ignored.
* Soroban Mode is especially useful together with
  clipboard monitoring software.
