■ Overview

Mouse Spot is a lightweight, compact utility.

It highlights the current mouse position when you click.
It can be used to emphasize a location during presentations,
or to highlight the moment when an action is selected or confirmed
with a mouse click.

■ How to Use

Double-click myXMouse.exe to launch the program.

Press the CTRL key to enable the display of the cursor position,
then press and hold a mouse button to activate the effect.

The press-and-hold duration can be set between 100 and 1000 ms
(the default is 200 ms).

The effect is not activated by a normal click.
It is activated only when the mouse button is held down briefly.

※ This setting can be changed from the tray menu.

■ Notes

・Settings are not saved.
・The program does not use the Windows Registry.
・The program may not function correctly depending on other
  mouse-control software or custom mouse settings.
