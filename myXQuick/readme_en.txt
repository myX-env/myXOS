[Development Environment]
・Windows 10
・.NET Framework 4.8

[Overview]
A memory-resident tool that summons the
myXKey (XK) key navigation
menu to the vicinity of the cursor
when the Pause/Break key is pressed.

[Usage]
Execution command:
myXQuick.exe "Program to launch" "Argument 1" "Argument 2" ...
Example:
myXQuick.exe "D:\app\Tool.exe" memo.txt test.txt
* The default target program is myXKey.exe.
